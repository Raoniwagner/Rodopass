Escopo

O que está incluído

01
Coleta automática via API de Telemetria
Integração com a API de telemetria dos veículos para extração diária dos registros de motoristas, eliminando exportação manual de planilhas.
02
Tratamento e padronização dos dados
Limpeza automática dos registros, ajuste de datas e horários, e organização dos dados por motorista e jornada em banco de dados local.
03
Integração com Tacom e SitGis
Validação do início de viagem e jornada via API Tacom, e validação dos horários de início e fim de jornada via API SitGis.
04
Motor de regras de jornada
Classificação automática do início de jornada (garagem ou ponto de controle), cálculo de tempo de deslocamento com parâmetros configuráveis pelo operador — sem necessidade de alteração no código.
05
Geração da planilha no formato Praxio
Exportação automática do arquivo final no layout exigido pelo Praxio, com dados tratados e prontos para importação, reduzindo erros no processo de carga.
06
Instalador Windows + atualizações automáticas
Instalador .exe para distribuição, funcionamento 100% local sem dependência de internet contínua, e sistema de atualização automática.

Fora do escopo desta proposta Integração automática direta via API com o Praxio (fase 1 contempla importação manual assistida). Pode ser incluída em uma fase 2 mediante novo orçamento.

Condições gerais

Informações importantes

Acesso às APIs Para cumprimento do prazo, é necessário que o cliente forneça as credenciais de acesso às APIs Telemetria, Tacom e SitGis — com ambiente de homologação — no início do projeto.
Layout da planilha Praxio O modelo do arquivo de importação do Praxio deve ser fornecido pelo cliente antes do início da fase de geração do arquivo final.
Alterações de escopo Mudanças nas regras de negócio ou inclusão de novas funcionalidades após o início do desenvolvimento serão tratadas como aditivo contratual, cobradas à parte na mesma taxa horária.
